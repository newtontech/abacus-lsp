# ABACUS Pseudopotentials and Basis Sets

> Source: http://abacus.deepmodeling.com/en/latest/advanced/pp_orb.html
> Fetched: 2026-06-12

## Basis Sets

ABACUS supports two basis set types, controlled by `basis_type` in INPUT:

### Plane Wave (PW)
- Default basis type
- Size controlled by kinetic energy cutoff (`ecutwfc`)
- No additional files needed

### LCAO (Linear Combination of Atomic Orbitals)
- Requires numerical atomic orbital files
- Files specified in STRU under `NUMERICAL_ORBITAL` section
- Angular part uses real spherical harmonics

Orbital ordering inside ABACUS:
1. Species (matching ATOMIC_SPECIES order in STRU)
2. Position (matching ATOMIC_POSITIONS order in STRU)
3. Angular momentum (s, p, d, f, ... ascending)
4. Zeta number
5. Magnetic quantum number m: 0, 1, -1, 2, -2, ..., l, -l

### Orbital Nomenclature

Orbital files follow naming convention like: `Si_gga_8au_60Ry_2s2p1d.orb`
- Element: `Si`
- XC functional: `gga`
- Cutoff radius: `8au` (atomic units)
- Energy cutoff: `60Ry`
- Orbital composition: `2s2p1d` (2 s-type, 2 p-type, 1 d-type)

### Generating Atomic Orbital Bases

Theoretical background:
- Spillage method: Chen M, Guo GC, He L. J. Phys.: Condens. Matter, 2010, 22(44): 445501
- PTG DPSI: Lin P, Ren X, He L. Phys. Rev. B, 2021, 103(23): 235131

## Pseudopotential Formats

ABACUS supports both norm-conserving and ultrasoft pseudopotentials.

### Norm-conserving
- UPF (.UPF format)
- UPF2 (new .UPF format)
- VWR (.vwr format)
- BLPS (bulk-derived local pseudopotential)

### Ultrasoft
- UPF
- UPF2

## Pseudopotential Types in STRU

Five options for `pseudo_type`:
- `upf` - .UPF format
- `upf201` - new .UPF format
- `vwr` - .vwr format
- `blps` - bulk-derived local pseudopotential
- `auto` - automatically identified (default)

## SOC (Spin-Orbit Coupling) Pseudopotentials

For SOC calculations (`lspinorb=1`), full-relativistic pseudopotentials are required.

### Identifying SOC Pseudopotentials

Check UPF header (`PP_HEADER` section):
```xml
<PP_HEADER
   relativistic="full"
   has_so="T"
/>
```

- `relativistic="full"` = full-relativistic pseudopotential
- `has_so="T"` or `has_so="1"` = SOC information included

### Usage Rules

1. **SOC calculations** (`lspinorb=1`):
   - Required: Full-relativistic pseudopotentials with `has_so=true`
   - Error if not met: "no soc upf used for lspinorb calculation"

2. **Non-SOC calculations** (`lspinorb=0`):
   - Flexible: scalar-relativistic or full-relativistic
   - Auto-conversion: full-relativistic PP is averaged to scalar-relativistic

3. **Ultrasoft (USPP)**:
   - Constraint: Full-relativistic USPP must be used with `lspinorb=true`

## BSSE Correction (Basis Set Superposition Error)

"Empty" or "ghost" atoms are supported. Defined by adding "empty" suffix to element name (e.g., `H_empty`).
Used for calculating formation energies with BSSE correction.

Example: H2O formation energy uses four STRU files:
- STRU_0: normal water molecule (E(H2O))
- STRU_1: single O atom (E_O)
- STRU_2: 1st H atom (E_H1)
- STRU_3: 2nd H atom (E_H2)

Note: Adjust `ntype` parameter in INPUT for ghost atoms.

## APNS Project (ABACUS Pseudopotential-Numerical atomic orbital Square)

Initiated to provide high-quality pseudopotentials and numerical atomic orbitals.

- APNS website: test data and results
- APNS workflow (GitHub): high-throughput testing
- Currently in development stage
- Community contributions welcome

Recommended set: APNSv1.0 pseudopotential and orbital set for general usage, available via AIS square website.
